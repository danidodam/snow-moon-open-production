# Screenplay and scene breakdown

Place the production screenplay and scene breakdown here. Use Markdown or plain text for scripts so changes can be tracked with Git.

Suggested files:
- `screenplay.md` — current shooting script
- `scene-breakdown.md` — scene summaries, locations, characters, and purpose
- `dialogue-and-narration.md` — dialogue/narration if maintained separately

For each scene, use stable IDs such as `SC01`, `SC02`. Note whether text is directly from the source, adapted, or newly written. Do not include source text that you do not have permission to redistribute.
