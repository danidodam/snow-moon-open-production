# Public release checklist

- [ ] README accurately describes the actual production.
- [ ] Script and scene breakdown are included where permitted.
- [ ] Character reference images and storyboards are included or linked.
- [ ] Prompts are recorded; reconstructed prompts are clearly labelled.
- [ ] Tool and model names/versions are recorded where known.
- [ ] Generated clips have a manifest and valid links.
- [ ] CapCut workflow and export settings are documented.
- [ ] Music and sound effects are listed with licenses/permissions.
- [ ] Source-work attribution and license have been verified.
- [ ] Repository license is appropriate for the files actually being licensed.
- [ ] No API keys, passwords, private data, or restricted assets are included.
- [ ] Large files use a suitable hosting method.
- [ ] Final movie link has been tested.
- [ ] Another person can follow the reproduction guide.
