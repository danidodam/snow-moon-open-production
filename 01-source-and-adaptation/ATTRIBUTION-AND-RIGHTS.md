# Attribution and rights checklist

Complete this before public release.

- [ ] Confirm the official source-project URL.
- [ ] Confirm the source work's exact license and any adaptation conditions.
- [ ] Confirm the required writer/source attribution.
- [ ] Identify which screenplay and production materials are original contributions.
- [ ] Identify all external images, fonts, music, sound effects, and other assets.
- [ ] Record the license/permission for each asset.
- [ ] Remove or replace assets whose redistribution rights are unclear.
- [ ] Add a per-file or per-folder license note where terms differ.
- [ ] Make sure the final film's credits match the documented credits.

**Credit wording to verify:** “Written by Vitalik Buterin” and “Directed by Idowu Daniel.” Do not publish this wording as verified until it has been checked against the source project and the actual production credits.
