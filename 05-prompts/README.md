# Prompts and generation logs

This folder records the meaningful prompts used in the production. Include the prompt as actually used where available; label reconstructed prompts as reconstructed rather than presenting them as exact originals.

For each prompt, record:
- Prompt ID and date
- Scene/shot/asset ID
- Tool and model/version
- Full prompt and negative prompt (if used)
- Reference images supplied
- Aspect ratio, duration, seed, and other relevant settings (if available)
- Resulting file(s)
- What worked, what failed, and subsequent changes
- Rights or service restrictions relevant to the output

Never include API keys, access tokens, private account information, or secret URLs.
