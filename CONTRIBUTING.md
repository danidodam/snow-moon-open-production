# Contributing

Thanks for helping improve the *Snow Moon* production archive.

## Useful contributions

- Correcting or clarifying production documentation
- Adding missing prompt and generation settings
- Improving scene/shot IDs and continuity notes
- Documenting CapCut editing steps
- Adding reusable assets that the contributor has the right to share
- Recording accessibility improvements or lessons learned

## Before submitting

1. Confirm that you own the material or have permission to redistribute it.
2. Include attribution and license information for third-party material.
3. Remove API keys, tokens, private messages, personal information, and confidential project files.
4. Use stable scene and shot IDs where possible, such as `SC03-SH02`.
5. Do not upload third-party software, model weights, or paid assets unless redistribution is expressly permitted.
