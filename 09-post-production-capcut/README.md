# CapCut post-production

Document the CapCut workflow used for the final cut. CapCut project files may depend on local media paths, app versions, fonts, effects, templates, or licensed features; do not assume another creator can open the project unchanged.

Include:
- CapCut platform and version (desktop/mobile, version number)
- Timeline organization and track naming
- Clip order and scene/shot IDs
- Transitions, titles, effects, color adjustments, and keyframes
- Music/SFX placement and mixing decisions
- Subtitle/caption workflow
- Export resolution, frame rate, codec/container, and bitrate if known
- Known dependencies and missing-media relinking instructions

Only share the CapCut project file if it is safe and permitted to share. Include the media manifest and explain how to relink assets on another computer.
