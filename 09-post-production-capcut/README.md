# CapCut post-production

Documentation of the CapCut workflow used for the final cut. 

Include:
- CapCut Pro For PC 
- After generating the whole videos with Google flow; it amounted to about thirty (10 seconds) videos. 
- I imported them in the order which they were generated. 
- Transitions, titles, effects, color adjustments, and keyframes
- Music/SFX placement and mixing decisions were added as it correlates with the script
- Subtitle/caption was autogenerated by Capcut
