# Production workflow

Document the real workflow used, including manual steps and failed attempts that affected the final process. Avoid describing steps as automated if they were performed manually.

1. Script and scene breakdown
2. Character reference creation and approval
3. Storyboard creation
4. Prompt preparation and visual generation
5. Clip review and selection
6. Audio selection and placement
7. CapCut assembly and finishing
8. Export and quality review

For every step, record inputs, outputs, tools, decision criteria, and known limitations.
