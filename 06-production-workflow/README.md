# Production workflow

The real Workflow for this video is; firstly i restructured the Chapter one into a Drama Script after doing that. I asked ChatGpt to suggest Chaacters. Then I made sure each character has a moodboard for the whole movie for consistency. Then i also generated a picture for the  scenes. A picture containing about 20 scenes or less. Then i go to Google flow; paste the script i copied; ask it generate the short 10secs video, add the character moodbaoards and the story moodboards to the prompt as reference.  

## Current pipeline

1. Script and scene breakdown
2. Character reference creation and approval
3. Storyboard creation
4. Prompt preparation and visual generation
5. Clip review and selection
6. CapCut assembly and finishing
8. Export and quality review
