# File naming conventions

Use stable, descriptive IDs to connect the script, storyboard, prompts, generated clips, and edit.

- Scene: `SC01`
- Shot: `SC01-SH01`
- Character: `CHAR01`
- Prompt: `PROMPT001`
- Clip: `CLIP001`
- Audio asset: `AUDIO001`

Example:
- `04-storyboards/SC01/SC01-SH01.png`
- `05-prompts/PROMPT001-living-room-wide.md`
- `07-generated-media/SC01-SH01-v01.mp4`

Use `v01`, `v02`, etc. for iterations. Do not overwrite a selected final file without updating the manifest.
