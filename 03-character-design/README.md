# Character design and continuity

Store only reference images that you have permission to share. Keep the character's visual rules in a Markdown file so other creators can reproduce the intended appearance.

Suggested structure:
- `character-bible.md`
- `characters/<character-id>.md`
- `references/` — approved reference images
- `character-reference-register.csv` — image source, scene usage, rights, and notes

Use consistent character IDs, and link each image to the scenes/shots where it was used.
