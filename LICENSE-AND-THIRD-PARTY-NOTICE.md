# License and third-party materials — review before release

The project brief says the source work *Snowmoon* is published under GNU GPL v3. Before publishing this adaptation's repository, verify the source repository, exact license file, attribution requirements, and any additional terms that apply to adaptations and production materials.

## Choose a license for this repository deliberately

Do not copy a license into this repository merely because the source project uses GPL v3. Decide which original materials you control and are willing and able to license. If you intend to use GPL v3 for eligible original files, include the official GPL v3 text and add appropriate copyright/license notices to those files. The official text is available at https://www.gnu.org/licenses/gpl-3.0.html.

## Third-party assets register

For every external asset, record:
- Asset name and repository path or URL
- Creator / source
- License or permission basis
- Attribution wording required
- Whether redistribution is allowed
- Any restrictions or access requirements

Do not redistribute material when its license or permission is unclear. You can document that a tool or service was used without distributing the tool, model weights, or service output files where redistribution is restricted.

This file is a checklist, not legal advice.
