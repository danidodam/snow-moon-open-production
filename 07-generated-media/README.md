# Generated video and image media

This folder may contain small, shareable examples or manifests pointing to larger hosted files. Do not commit large video files directly without considering repository size and Git LFS.

For each clip, maintain a manifest with:
- Clip ID and filename
- Scene/shot ID
- Generation tool/model and version
- Prompt ID
- Duration, resolution, frame rate, and format when known
- Whether it was edited, retimed, cropped, or upscaled
- License/redistribution notes
- External download link, if applicable

Never use a link that requires sharing private credentials. Confirm external links work before release.
