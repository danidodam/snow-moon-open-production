# Storyboards

Add storyboard images in scene-specific folders, for example `SC01/SC01-SH01.png`. Include a shot list that explains what each frame is intended to communicate.

For each shot, document:
- Scene/shot ID
- Shot size and camera angle
- Character action and screen direction
- Background/location
- Intended duration
- Transition in/out
- Prompt or generated asset ID
- Continuity notes

A storyboard image is not automatically licensed for redistribution simply because it was generated; record any relevant tool terms and rights notes.
